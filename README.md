# Ambient Clinical Scribe

> **Status: work in progress.** This README is a stub for Phase 1 (repo scaffold + data
> pipeline). It will be fully rewritten in Phase 5 with an architecture diagram, setup
> instructions, results, and limitations once training and evaluation are complete.

Fine-tuning Llama 3 8B Instruct with QLoRA to generate structured SOAP-style clinical notes
from doctor-patient dialogue transcripts, using the [MTS-Dialog](https://github.com/abachaa/MTS-Dialog)
dataset.

This is a portfolio project, not a clinically validated tool.
